# What is Python?
Python is a high level programming language, but what is a high level programming language?
A high level programming language is a simplified way to code, it has syntax that resembles human language and makes the code easier to read. (Simple)

Python is a general purpose programming language, which means you can use it for pretty much anything.
Whether you want to use python to make a desktop application, do web development, etc. Python is able to do it.
